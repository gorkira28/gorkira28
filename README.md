## Current portfolio project

### Texas Diabetes Vulnerability Atlas

A reproducible county-level study of where diagnosed diabetes, obesity, physical inactivity, and lack of health insurance overlap across Texas.

- **Methods:** age-adjusted prevalence, percentile-based composite scoring, Spearman correlation, sensitivity analysis
- **Tools:** Python, SAS, QGIS/ArcGIS-compatible GeoJSON
- **Data:** CDC PLACES 2025 release and U.S. Census Bureau cartographic boundaries
- **Deliverables:** validated analysis pipeline, county atlas, statistical tables, SAS companion program, and documented limitations

Repository: [gorkira28/texas-diabetes-vulnerability-atlas](https://github.com/gorkira28/texas-diabetes-vulnerability-atlas)
